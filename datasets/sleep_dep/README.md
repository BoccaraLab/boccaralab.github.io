# Sleep Deprivation Dataset — Boccara Lab

This repository contains the Sleep Deprivation Dataset exported from the lab's spreadsheet.

**Files**
- `sleep_deprivation_db.xlsx` — original Excel (copied here)
- `sleep_deprivation_db.csv` — CSV export (exact conversion)
- `sleep_deprivation_db.json` — JSON records for the interactive table
- `index.html` — interactive Tabulator table for GitHub Pages
- `analytics/` — summary tables and plots

**Columns**
Brain Region, Brain Area, Target, Method, Submethod, Model, Effect, Wake effectiveness, NREM effectiveness, REM effectiveness, Manipulation duration ( in relation to effectiveness), Rodent, Strain, Sex, Age, Sleep target, Target maturation timeline, Cognitive side effects, Metabolic side effects, Other effects, Unnamed: 20, First author, Year, Reference, link
