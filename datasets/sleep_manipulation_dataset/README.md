# Sleep Manipulation Dataset — Boccara Lab

This repository contains the Sleep Manipulation Dataset exported from the lab's spreadsheet.

**Files**
- `sleep_manipulation_db.xlsx` — original Excel (copied here)
- `sleep_manipulation_db.csv` — CSV export (exact conversion)
- `sleep_manipulation_db.json` — JSON records for the interactive table
- `index.html` — interactive Tabulator table for GitHub Pages
- `analytics/` — summary tables and plots

**Columns**
Brain Region, Brain Area, Target, Method, Submethod, Model, Effect, Wake effectiveness, NREM effectiveness, REM effectiveness, Manipulation duration ( in relation to effectiveness), Rodent, Strain, Sex, Age, Sleep target, Target maturation timeline, Cognitive side effects, Metabolic side effects, Other effects, Reference, Author, Year, link, Impact factor at publication
